# Editor shortcuts

Shortcuts apply within the editor and do not intercept ordinary typing in inputs.

| Action | Shortcut |
| --- | --- |
| Group same-layer selection | Ctrl/Cmd+G |
| Ungroup, preserving objects and draw order | Ctrl/Cmd+Shift+G |
| Enter selected group | Enter on canvas; Enter group button from Objects |
| Leave group editing, retaining selection | Escape |
| Cancel current gesture | Escape, before leaving group context |
| Nudge | Arrow: 1 map pixel |
| Larger nudge | Shift+arrow: one grid cell when visible/snapping, otherwise 10 px |
| Copy / paste across projects | Ctrl/Cmd+C / V |
| Duplicate | Ctrl/Cmd+D |
| Delete selection | Delete / Backspace |
| Undo / redo | Ctrl/Cmd+Z / Shift+Z; Ctrl/Cmd+Y also redoes |
| Save locally | Ctrl/Cmd+S |
| Temporary snap bypass | Hold Alt during dragging, including release |
| Pan | Middle drag or Space+primary drag |
| Zoom around pointer | Mouse wheel |

In Objects, Up/Down/Home/End move focus; Enter/Space selects; Shift-click adds/removes selection. Reveal selected clears filters, expands its group and scrolls to the object. On layer tree rows, Up/Down navigates, Left/Right collapses/expands a group and Enter activates a concrete layer or toggles a group. Tab reaches named visibility, lock, reorder and overflow controls. Rename accepts Enter or blur; Escape cancels its text change.

## Openings and room floors

Opening: click a wall to place repeatedly; Alt bypasses optional grid/free-space snapping; Escape returns to Select. Space/middle drag pans without placing. A selected opening drags along its wall; Escape restores an active drag. Detect rooms and Regenerate room floor are explicit buttons with preview/confirmation, not automatic keyboard actions.
