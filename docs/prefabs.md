# Reusable compositions

Choose **Save as reusable prefab** above the canvas. Choose the current selection, an object group, a layer or an entire layer group. The dialog reports the deduplicated object count, locked content, image dependencies and hidden exclusions. Parent layer/group visibility applies. **Include hidden objects** is off by default; locked visible objects are included and Editable retains their locks.

Review external relationships and explicitly choose **Include required objects** when appropriate. A door/window needs its wall, a linked label needs its owner, and a room's historical provenance needs its referenced walls. Hidden dependencies require explicit hidden inclusion. Optional external label ownership, room provenance and junction annotations may instead be detached explicitly; doors/windows cannot be detached from their wall. Missing sources never capture the whole project. Cancel leaves the editor untouched.

Choose **Editable** to keep individual objects, relationships, layers, order and groups. Choose **Flattened** for one transparent image: it cannot reconstruct the original parts. The source map remains editable in either case. Set title, description, category, tags, anchor, default size and applicable map types. Preview first, then confirm saving. Preview cancellation writes no library item. A stale import preview must be recreated after another library mutation.

The center, top-left and bottom-center anchors refer to the nominal composition bounds. Transparent crop margins do not move that anchor. Rendering at 2× improves pixel resolution without doubling the intended map size. Grid is excluded unless explicitly selected; no project background, selection handles or guides enter the image. Fully transparent output is refused.

Open **Asset library → Prefabs**. Editable/Flattened labels accompany the preview. Categories, subtree search, favorites, tags, collections and bulk management are the same as for other assets; collapsed categories still include descendants. Metadata edits affect only future placements. **Native** preserves stored composition dimensions, not preview-image pixels. Grid uses battlemap cells; World needs configured physical scale. A missing scale gives a visible native fallback rather than assuming metres or feet.

Choose **Place prefab…**, internal layers or active layer, a uniform scale multiplier and rotation. The canvas preview marks the anchor. Click to place; Alt bypasses grid snap; Escape cancels. The **Place at preview anchor** button is keyboard accessible and initially uses the map center. Active-layer placement preserves paint order and bakes inherited hidden/locked flags into objects. Internal layers are copied into their own new layer group. Undo/redo removes/restores the entire placement in one action, including new layers/groups.

Instances are independent. Ungroup an existing same-layer group to edit its members. Cross-layer compositions use the copied layer group and multi-selection; the existing architecture does not support a single cross-layer object group. Changing or removing the library definition never changes placed objects; image dependencies remain protected by project references. Image-backed Flattened entries also have a shared ordinary stamp image role. Use the Prefabs placement workflow to preserve its composition anchor and stored physical/native dimensions.

Use **Export ZIP** to transfer a prefab. All image dependencies and embedded immutable wall definitions are included; import into another library through the existing **Import assets** preview/review/confirm workflow. Full backups preserve definitions, category metadata, collection membership, previews and bytes. A missing image blocks preview/placement, without placing half the composition.

Schemas: `public/asset-templates/mapweaver-assets-v2.schema.json` and `prefab-v1.schema.json`. The JSON Schemas describe the portable envelope; the shared project parser additionally validates every object, reference, dimension, resource budget and relationship. Ordinary manifest-1 stamps/sidecars still work. Technical decisions and limits: [ADR 0019](adr/0019-reusable-compositions.md).
