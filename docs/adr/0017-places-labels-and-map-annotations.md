# ADR 0017 — Places, linked labels and map annotations

Accepted, 24 September 2026, Sprint 22.

Place, Label, Legend and Compass extend the existing `MapObject` union. They use the same object IDs, layer membership, groups, transforms, history, local persistence, asset registry and PNG scene. There is no parallel cartographic document or label database.

A Place stores its type, short name/note/tags/importance, optional stamp ID, explicit cartographic/world size mode, captured pixels-per-kilometre reference, normalized anchor and ordinary map-coordinate bounds. Built-in type names are editable defaults, not reserved categories. Cartographic width is in map pixels at 1× export; 2× export doubles output pixels. World placement reuses applicable asset sizing defaults. Changing geographic scale never silently changes saved geometry. Zoom never changes either mode's geometry. Compass is independent artwork, not a second map-north setting.

A Label is a separate text object. Optional `ownerId` points to one non-label object in the same layer. Its unrotated anchor is owner-center plus explicit map-axis offset. Chains/cycles are forbidden. Untouched labels follow owner position/bounds; explicitly transformed labels derive their offset from their new coordinates, including repeated final pointer updates. Group transforms include dependent labels and transform text size/rotation together. Ordinary owner dragging preserves label style/orientation. Linked labels may be selected and dragged independently. Locks on dependent labels block moving an owner. Copying an owner includes labels and remaps links; a label-only copy detaches. Cross-layer moves include the owner/link assembly. Owner deletion lists dependent objects before one reversible deletion. Layer deletion removes the entire same-layer relationship. Appearance flags and z-order remain independent.

Text remains plain text plus concrete layout/style data. The application bundles four unmodified Liberation Sans variants under SIL OFL 1.1 (`public/fonts/LICENSE_LIBERATION`). Format 12 pins these font bytes and extracted advance metrics. `scripts/font-metrics.py` regenerates metrics from the bundled files without external packages. There is one supported family, normal/bold/italic/bold-italic; no arbitrary font URL or machine-dependent family. These runtime resources ship with Mapweaver, not separately in every `.mapweaver` document. Changing their layout metrics requires a new format/layout decision.

Layout uses explicit glyph advances, word/character wrapping, line height and nonnegative tracking. Editor and PNG draw the same glyphs with the same painter. No HTML, path text, ligature engine, bidirectional/complex-script shaping or small caps. Unsupported characters render as `?` while original text remains editable. This is deterministic fallback, not silent replacement of the saved text. A bounded 512-entry cache keys text and the entire style. Missing bundled fonts block PNG with a restore/reload message; declared missing symbol assets also block PNG. No platform fallback is exported.

Label bounds derive from text layout and a uniform `layoutScale`; runtime validation checks them. Stroke and halo padding are part of the layout. Rotation is around object center. Leader lines use the same map endpoints/z-order in editor and export; selection-only link lines are excluded from PNG. A max-width text box retains its chosen width, including for shorter lines. Linked text is independent of owner name after creation.

Avoid overlaps is an explicit deterministic preview: up to 100 selected labels, 25 fixed candidates per label, minimum overlap score against other objects and already placed preview labels. It is a bounded heuristic, not a guarantee that a dense map can be made collision-free. It never runs during pan/zoom or changes autosaved data before Apply. Legend entries are concrete ordered snapshots; Refresh from map displays selectable proposed entries before replacement. Editing places never edits an existing legend implicitly. Legend text wraps within columns. The existing geographic scale-bar model remains the only scale bar.

Limits: 2,000 labels/document; 2,048 characters/label; 1,024 characters/place note; 16 tags of 40 characters; type 60 characters; name/title/legend text 120; 64 legend entries; 1–4 columns; font size 6–200; tracking 0–20; line height 1–3; wrap width 20–2,000; outline 0–12; padding 0–40; layout scale .001–1,000. Existing object, coordinate, image, JSON and history budgets also apply.

Format 12 validates all discriminated fields, owner references, bounds, same-layer membership and stamp asset roles at the shared admission boundary. SQLite schema 4, conflict handling, recovery, portable ZIP and full-backup containers are unchanged. Retained migrations preserve older battlemaps/routes and write current format 12; old binaries refuse new documents. No Windows package, dependency, network service, account, lore model or asset taxonomy is added.
