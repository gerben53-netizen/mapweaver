# ADR-0058 — Linear / Timber Generated Walls

Accepted 3 October 2026. Additive to ADR-0051/0055/0057. `generatorType: linear` adds a longitudinal constructed-timber strategy to the existing immutable Generated Wall registry. Native Wall paths, opening ownership, physical widths, history, local persistence and Campfire semantics remain canonical. No parallel wall system or generated scene-stamps.

Three required roles: `beam-long` (4 × 0.5 ft), `beam-medium` (2 × 0.5 ft), `beam-short` (0.5 × 0.5 ft), two DEV variants each at 256 source px/ft. All members author horizontally (+X grain), full-canvas-center anchor. `timber-rustic@dev-1` and `timber-refined@dev-1` share components with metadata-driven Regularity/Variation defaults (65%/55% and 95%/20%). Root fields remain zero; rock Roughness is rejected. Format 12 admits the new immutable IDs/strategy with the existing seed/regularity/variation fields; no schema migration, old recipe conversion or production-art replacement.

The evaluated longitudinal model fits framed/refined timber. Repeated transverse/palisade posts would require cross-section artwork and a different spacing/coverage contract, so they are deferred rather than forced into this vocabulary. No Spacing/Density parameter, dedicated post/corner/jamb catalog or persisted global graph is introduced.

Width presets add 1/2/4/6 half-foot rows for Thin/Standard/Heavy/Massive; custom widths uniformly adjust nominal member scale to width/ceil(widthFt/0.5). Seed-indexed weighted choice avoids the previous variant; row starts stagger by length. Curvature probes cap tangent change to approximately 0.14 rad, repack into shorter stock and cap outer-row travel at stock length. Short terminal stock is source-cropped, never stretched into a continuous texture strip. Source-cropping is also used on curves. Grain follows the local member axis with at most ~0.43° rustic skew; short square join stock follows local joins/fans. No arbitrary free rotation/mirroring of long grain.

Coverage requires a fully opaque rectangular source core inside a two-source-pixel transparent gutter. Four-percent-row-depth longitudinal overlap and 12% depth overlap bridge resampling seams. Short square join stock uses 10% longitudinal overlap. Ordinary short stock bridges rotating members and fills sharp turns/closed seams. Native openings split spans and reuse the shared opening-only clip. Ends terminate at the path end without auto-closure or a nominal rectangular wall mask. T/cross walls overlap normally and remain independent. Development components are diagnostic cut wood with arrows/grain, not Premium artwork, floor textures or reused Living Root pixels.

The local linear arc lookup uses the shared bounded sampler at 0.05-map-pixel tolerance, normalized to canonical segment lengths. It accelerates repeated row/curvature probes; it does not change path nodes, canonical length, opening positions or other strategies. Tables are weakly cached by canonical geometry, with existing 8192 sampling and 12000 placement bounds. Admission runs the bounded layout before rendering. Shared 0.5 editing preview / final surface quality, 4 Mi-pixel surface, 16 Mi-pixel cache/source and 128-surface limits remain.

DEV choices are exposed only in non-installer builds, clearly labeled; installer builds hide new DEV choices but resolve exact saved selections. No new production content or installer is delivered. Reproducible scripts create diagnostic components and a standalone six-file Production Artwork Specification Pack. Recommended commissions: Premium Refined Timber first, Premium Rustic / Heavy Timber second. Production admission requires a separate actual-art visual review.

Existing Living Root, masonry (including Pale Stone/Marble/Rough Stone), Rock/Cave and legacy geometry/artwork remain unchanged. Campfire continues to receive ordinary walls/doors/windows and Window Lights using its read-only canonical contract. No contract additions or runtime-state changes.
