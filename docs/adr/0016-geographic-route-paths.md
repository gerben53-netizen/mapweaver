# ADR 0016 — Geographic route specializations

Accepted 24 September 2026 for Sprint 21.

River, Road and Border specialize the existing Path model. Absolute nodes, relative Bézier handles, insertion, nearest-point projection, length, transforms, transactions and asset references remain shared. No second editor or persistent network graph is introduced. The `route.kind` discriminated union must match `pathKind`; admission rejects foreign settings and unknown keys. Generic paths and walls cannot contain route settings.

Presets copy concrete appearance into each object. Widths are canonical map pixels. A route stores its selected `px | km | mi` unit and the positive pixels-per-unit reference captured from the current map scale. Choosing another unit recomputes that reference without resizing the object. Numeric width changes convert through this reference; Properties also displays actual physical width/length at the current map scale. Changing geographic scale alone never changes artwork. Uniform object/group scaling scales widths, outlines, markings and dash lengths. Nonuniform matching scales nodes/handles on each axis and scales appearance by the smaller absolute axis factor, matching the existing path transform policy. Pixel/physical width values therefore change deliberately with an object scale gesture. Texture patterns remain map aligned; their explicit texture scale stays fixed.

A river has an open directed centerline. Its effective width interpolates linearly by arc distance between `startWidth * startFactor` and `endWidth * endFactor`. Reversal swaps nodes/handles and both endpoint width/factor pairs, preserving the visible contour while reversing source/mouth. Splitting evaluates the profile at the split node and gives both resulting routes that same boundary width. Extending redistributes the endpoint profile over the new total length; it does not preserve local hydrology. Upstream-wider and bounded self-crossing diagnostics warn without modifying geometry.

Rivers derive a cached ribbon from the existing adaptive samples. Positive-winding trapezoids and round joins/caps share a single fill, including texture fills. Roads use exact cubic strokes, bounded joins/caps, an outline and optional dashed center marking. Borders use exact strokes for solid/dashed/dotted styles and two offset sampled lines for double style. Halo uses three bounded translucent strokes, not a general filter engine. Translucent objects compose their artwork once into a reusable scratch canvas clipped to visible device bounds, then apply object opacity once. This avoids accumulated alpha under banks and markings without allocating an unbounded map-sized surface.

Snapping uses the shared eight-screen-pixel contract, inherited layer/group availability and Alt bypass. Endpoint/node/segment targets precede explicit land Area edges, then existing guides/grid. Straight-segment projection is analytic so exact T junctions do not inherit library lookup-table residuals. Explicit node junction IDs are advisory and remapped by the existing clipboard pipeline; missing/moved targets do not corrupt the route. Endpoint-coordinate indexing and at most two explicit endpoint projections per route produce temporary same-type cap patches. They never merge objects, create junction entities or link road/river crossings. Appearance follows normal z-order. Differently styled or translucent overlapping objects retain their individual compositing semantics.

Border-from-Area is a previewed, bounded copy of one selected canonical ring, including selectable hole contours. Maximum 256 nodes; larger contours must first be explicitly simplified. Later Area edits do not move the Border. Type conversion previews the concrete result and property loss, preserves identity/layer/order and commits once. Wall conversion is excluded to protect opening relationships. A closed Border is not a political region; existing Area duplication remains separate.

Limits reuse Path: 256 nodes/object, 8,192 samples/object, 20,000 nodes and 250,000 samples/document, coordinate magnitude 1e9, effective width at most 1,024 px. Route outlines/halos/markings max 128 px, width factors 0–4, positive dash/gap max 10,000 px, texture scale .01–100. At most 20,000 referenced target segments are admitted for endpoint junction checks. River self-crossing diagnostics stop above 512 samples and disclose that omission. Contours and scratch surfaces are derived only and never serialized.

Format 11 adds these route settings to the canonical project model. SQLite schema 4, local revision/conflict/recovery handling, portable ZIP and full backup container stay unchanged. Older binaries refuse new format documents. No dependency, cloud service, bridge/tunnel model, routefinding, hydrology, path text or political database is added. Bridge segment overrides are deferred until their interactions with splitting, reversal and textures can be implemented as one complete feature.
