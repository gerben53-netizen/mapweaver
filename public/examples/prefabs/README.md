# Prefab house demonstration

Open `house.mapweaver` through the project manager. It contains material walls with a door and window, a floor, desk furniture, a label and a small scatter outside. Import `house-editable.zip` and `house-flattened.zip` through Asset library > Import assets, then use the Prefabs tab. The latter was rendered at 2x without doubling the intended map size. Both use a 24-metre physical default width and center anchor.

The simple desk and wall atlas are original bundled Mapweaver demonstration artwork, reusable under CC0-1.0. Text uses the bundled OFL Liberation fonts; their license ships with Mapweaver. These are test illustrations, not third-party game assets. ZIPs include every required image and immutable wall material definition. Source objects stay independent.
