# Painterly Terrain v1

32 distinct generated materials in 11 families. Built into Terrain Brush with named presets, search, category filtering and scale preview. No import is needed for brush use. Optional mapweaver-terrain-painterly-fills.zip imports copies as ordinary Area fill patterns; importing does not register new brush IDs.

512x512 sRGB opaque PNG sources; shared renderer overlap-adds edges to a 384px periodic material, anchored in map coordinates. Painterly Fantasy is the supported theme family. Existing procedural paint is unchanged. IDs and pixels are immutable; revise the version for art replacements. Full prompts and SHA-256 are recorded in provenance.json.
