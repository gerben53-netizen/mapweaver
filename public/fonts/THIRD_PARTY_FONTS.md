OFL permits bundling with software provided copyright and license accompany each copy; fonts are not sold separately. Reserved Font Names apply to modified fonts. See https://openfontlicense.org/ofl-faq/. Variable originals are retained without duplicate static files; the UI exposes only the weights/styles below.
