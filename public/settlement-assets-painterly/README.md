# Painterly Settlements & Landmarks

31 separate transparent illustrations: 3 capitals, 4 cities, 4 towns, 3 villages, 4 castles, 3 harbors, 3 ruins, 2 towers, 2 temples and 3 landmarks. Temperate, arid and northern variants share muted ochre stone, slate roofs, northwest light and an elevated atlas perspective. These are intentionally exaggerated world-map symbols, not battlemap buildings or actual settlement footprints.

Available directly in Map Markers → Illustrated on Regional/World maps. Choosing a bundled image adds its content to the local library and embeds it into the active project. Repeated placements share the source. The standard ZIP can also be imported/exported through the Asset Library.

Semantic metadata uses explicit tags `marker:capital`, `theme:painterly-fantasy`, `style:painterly` plus ordinary `applicableMapTypes`. No filename inference. Tags survive library export/import; manual override also offers other stamps. Generator metadata is intentionally absent: settlements are user-authored semantic Places.

Wizard width defaults to 2.5% of physical map width × type factor × prominence. Capital 1.15; town .85; village .7; others 1. Prominence .75/1/1.3/1.65. Exact width in km is editable. Ordinary stamp placement from the Library uses the independent, fixed metre defaults in the manifest.

Images are bounded to 384 pixels on the long edge and retain source alpha. `catalog.png` shows all variants. `prompts.json` records exact generation prompts; `provenance.json` records source/output hashes. Generated with built-in imagegen; no external stock imagery.
