Back up and restore Mapweaver

Save writes one project to SQLite. Export project transfers one map. Back up all data copies the entire project and asset library.

Choose a backup destination outside Downloads. Wait for validation and for the browser to finish writing the file.

Restore all data first uploads and validates a ZIP. Save or export unsaved work in every open browser, then confirm Replace all local data. Cancellation is available before switching. Reload explicitly after success.

The old dataset remains in a sibling .operations recovery directory. Automatic recovery-point deletion is disabled. Never remove the active dataset or restore journal while Mapweaver runs. See BACKUP-RESTORE.md and TROUBLESHOOTING.md included with the package for full procedures.
