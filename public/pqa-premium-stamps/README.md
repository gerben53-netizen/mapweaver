# PQA Premium Stamp Families — Wave 2

22 production families, 69 original transparent PNGs. Authoring scale: 160 px/ft; map placement follows explicit physical footprints (10 px/ft in the acceptance maps). One library card per family; concrete variant selection is stored on the placed stamp.

The supplied Wave 2 archive reused Wave 1's `pqa-reconciled-stamps@1` identity. This separately delivered wave is packaged as `pqa-premium-stamps-wave-02@1`, using the supported independent-pack model. Family IDs, variant IDs, metadata and PNG bytes are preserved. Wave 1 keeps its existing identity; no overwrite, revision-conflict bypass or map migration occurs.

The ZIP contains only the production manifest and its 69 referenced PNGs. Work proofs, rejected candidates and authoring intermediates are excluded. `provenance.json` records source/archive and original-image hashes. Source artwork was supplied by the user for Mapweaver integration; this integration does not grant a new public artwork license.

Primary Development imports missing content through the governed default-content installation. New installations receive the same pack. Existing inactive/REPLACE assets and historical map references remain intact. QA uses a separate database.
